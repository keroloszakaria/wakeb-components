# نظرة عامة

توفر Wakeb Components **39 مكونًا Vue 3 بأنواع واضحة** بعقد موحد عبر **Vuetify 3 وPrimeVue 4 وshadcn-vue**. تشمل العرض والهوية والنماذج والتنقل والتخطيط وحالات التحميل والحوارات وجدول بيانات يقوده الخادم. اختر مزودًا واحدًا عند البناء مع الاحتفاظ باستيرادات المكونات العامة نفسها.

يصف الموقع **النسخة المحلية 0.8.0-alpha.0 غير المنشورة**. يدعم الإصدار العام 0.7 مزود Vuetify فقط. راجع [التثبيت](./installation) للأرشيف المحلي و[إعداد المزود](./providers) لـplugins البناء والتشغيل. كل من Vue وVite هو peer؛ ثبّت فقط اعتمادات المزود المختار. استورد المكونات بالاسم من `wakeb-components` وCSS مرة واحدة من `wakeb-components/style.css`.

تحتوي كل صفحة على معاينة تفاعلية ومثالَي Vue كاملين typed والخصائص وقيمها الافتراضية وتوقيعات الأحداث وslots ومتغيرات CSS ووجهة السمات والوصول وحدود المزودات. يشرح [التوافق والتغطية](./verification) الاختبارات وحدودها. تستخدم المعاينات داخل الموقع Vuetify، وتغطي اختبارات مستقلة المزودات الثلاثة.

يملك التطبيق stores وrouting ومثيلات i18n والصلاحيات وجلب البيانات وإرسال النماذج وتوليد الملفات. يعرض `WDataTable` الصفوف الممررة ويرسل الخيارات، بينما يرتب التطبيق البيانات ويقسمها لصفحات. خصص عبر props typed وslots والسمات والمتغيرات ذات النطاق. توفر [الـskill وMCP](./agents) العقود نفسها للـagents بالعربية والإنجليزية قبل كتابة الكود.
