# نظرة عامة

تضم Wakeb Components عشرة مكونات: النص المختصر، شريط التقدم، المؤشر نصف الدائري، الصور المتداخلة، مؤشر التحميل، Skeleton الصفحات، والخطوات الرأسية، والأزرار، والشارات، ولوحات Accordion. تظل ألوان التطبيق والأيقونات والترجمات في المشروع المستهلك.

Vue3.5 وVuetify 3.13.2+ هما peers. استورد المكونات بالاسم من wakeb-components.
لا تحتاج plugin تسجيل خاص أو router أو store أو نظام auto-import.

الحزمة تترك للمشروع النماذج والجداول وbadges الخاصة بالمجال والصلاحيات وطلب
البيانات وlayouts. تحتاج هذه الأجزاء عقودًا مستقلة قبل فصلها. يستقبل المكون
العام البيانات وخيارات العرض، ويحتفظ التطبيق بمنطق العمل.
