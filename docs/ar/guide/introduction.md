# نظرة عامة

تبدأ Wakeb Components بثلاثة مكونات عرض: النص المختصر، شريط التقدم، ومؤشر نصف
الدائرة. نحافظ على التفاعل المفيد المستخرج من Aware، وتظل ألوان التطبيق في adapters.

Vue3.5 وVuetify3 هما peers. استورد المكونات بالاسم من wakeb-components.
لا تحتاج plugin تسجيل خاص أو router أو store أو نظام auto-import.

الإصدار الأول لا يشمل النماذج والجداول وbadges الخاصة بالعمل والصلاحيات وطلب
البيانات وlayouts. تحتاج هذه الأجزاء عقودًا مستقلة قبل فصلها. يستقبل المكون
العام البيانات وخيارات العرض، ويحتفظ التطبيق بمنطق العمل.
