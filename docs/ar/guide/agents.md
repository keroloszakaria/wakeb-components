# أدوات الـagents: Skill وMCP

تحتوي **النسخة المحلية 0.8.0-alpha.0** على skill قابلة للنقل وسيرفر MCP مستقل
للقراءة فقط. يصفان المكونات الـ39 من نفس بيانات هذا الموقع. استخدم الـskill لقواعد
كتابة الكود والـMCP لقراءة العقود الدقيقة. لا يعدلان ملفات ولا ينفذان الكود الناتج
ولا ينشران حزمًا.

## تثبيت الـskill

نزّل [أرشيف الـskill](/downloads/wakeb-components-skill.zip) وفكّه داخل مجلد المهارات
الخاص بالـagent مع الحفاظ على البنية `wakeb-components/SKILL.md`.
المصدر داخل المستودع هو `.agents/skills/wakeb-components/`.
في Codex المسار الشخصي هو `~/.codex/skills/wakeb-components/`.
يمكن للـagents الأخرى قراءة `SKILL.md` والمراجع المرتبطة به من آلية المهارات أو
تعليمات المشروع الخاصة بها. أعد تحميل التطبيق بعد التثبيت.

مثال طلب:

> استخدم skill wakeb-components لبناء نموذج مراجعة عربي على PrimeVue، مع بريد
> إلكتروني مطلوب وحقل ملاحظات وحوار تأكيد يدعم الوصول بلوحة المفاتيح.

تشرح الـskill اختيار المزود والاستيراد المسمى وملكية الحالة واختلافات النموذج
والأحداث ومتغيرات CSS والوصول والتحقق. يربط الفهرس بمرجع مستقل لكل مكون، ليقرأ
الـagent ما يحتاجه فقط.

## تشغيل MCP محليًا

استخدم Node **22.14+**، ومن نسخة المستودع نفّذ:

```sh
npm ci
npm run agents:build
npm ci --prefix packages/mcp
node packages/mcp/server.mjs
```

ينتظر السيرفر رسائل MCP على stdin؛ عدم ظهور نص في الطرفية أمر متوقع. يكتب رسائل
البروتوكول على stdout. اربطه بعميل يدعم **stdio**. للعملاء الذين يستخدمون JSON
بمفتاح `mcpServers`، استبدل المسار بمسار المستودع المطلق:

```json
{
  "mcpServers": {
    "wakeb-components": {
      "command": "node",
      "args": ["D:/projects/wakeb-components/packages/mcp/server.mjs"]
    }
  }
}
```

للعملاء ذوي صيغة إعداد مختلفة استخدم نفس الأمر والمعاملات. في Windows استخدم
الشرطة `/` أو اهرب `\` حسب JSON، واحتفظ بالمسار ذي المسافات داخل معامل واحد.
يقرأ السيرفر الكتالوج نسبةً إلى ملفه، فلا يعتمد على مجلد عمل العميل. لا يحتاج API key.

يمكن أيضًا تنزيل <a href="/downloads/wakeb-components-mcp-0.8.0-alpha.0.tgz" download>أرشيف MCP</a>
وتثبيته داخل مجلد أدوات مستقل:

```sh
npm install ./wakeb-components-mcp-0.8.0-alpha.0.tgz
```

بعد ذلك استخدم المسار المطلق إلى `node_modules/wakeb-components-mcp/server.mjs` في
الإعداد السابق. الأرشيف نسخة محلية؛ لم تُنشر حزمة MCP على npm. لا تستخدم اسم حزمة
غير متحقق منه مع `npx`.

## الأدوات

| الأداة | المعاملات | النتيجة |
| --- | --- | --- |
| `list_components` | `query?: string` و`locale?: 'en' \| 'ar'` | الصادرات والأوصاف والمسارات المطابقة؛ البحث الفارغ يعيد المكونات الـ39. يشمل البحث الاسم والغرض وأسماء الخصائص. |
| `get_component` | `name: string` و`locale?: 'en' \| 'ar'` | الخصائص والقيم الافتراضية وتوقيعات الأحداث وslots ومتغيرات CSS ووجهة السمات والوصول وحدود المزودات ومثالا Vue كاملان. يقبل `WAccordion` أو `accordion`. |
| `get_guide` | `topic` و`locale?: 'en' \| 'ar'` | Markdown الدليل كاملًا ومحدد النسخة. الموضوعات: `installation` و`providers` و`customization` و`ssr` و`data-models` و`agents` و`verification`. |

تحتوي كل نتيجة على نسخة الحزمة و`status: 'unreleased'`. يرجع المكون غير المعروف
خطأ بدل اختراع واجهة له. يرفض مخطط SDK المعاملات غير الصحيحة. البحث الذي لا يجد
مطابقة يعيد قائمة فارغة.

## الموارد والـprompt

يعرض `wakeb://catalog` فهرس المكونات. لكل مكون مورد إنجليزي وعربي مثل
`wakeb://components/accordion/en` و`wakeb://components/accordion/ar`، بنفس عقود الأدوات.

يستقبل prompt المسمى `write_wakeb_component` معاملَي `task` و`framework`
(`vuetify` أو `primevue` أو `shadcn`) ويجهّز طلب تنفيذ يوجّه الـagent لقراءة الإعداد
والعقود أولًا. لا يولّد الكود ولا ينفذه بنفسه.

## سير العمل المقترح

1. طابق نسخة الكتالوج مع الحزمة المثبتة؛ واجهة 0.7 العامة مختلفة.
2. اقرأ `get_guide({ topic: 'providers' })` واختر مزود التطبيق مرة واحدة.
3. ابحث عبر `list_components({ query: 'modelValue' })` أو باسم المكون.
4. اقرأ `get_component({ name: 'WTextField', locale: 'ar' })` لكل مكون ستستخدمه.
5. اكتب ملفات Vue ذات أنواع صحيحة باستيرادات جذرية مسماة، ثم نفّذ فحص الأنواع والتفاعل في التطبيق.

مثلًا يستخدم `WTabs` خاصية `selectedTab` وحدث `updateTab`، ويستخدم `WTextField`
ربط `v-model`. يرسل `WDataTable` خيارات التحميل، بينما يجلب التطبيق الصفوف ويرتبها
ويقسمها إلى صفحات. لا يعتبر MCP خصائص المزود الأصلي جزءًا من عقد Wakeb تلقائيًا.

## الصيانة والتحقق

عدّل `docs/reference-data.mjs` و`docs/recipes.mjs` والعقود العامة، ثم شغّل
`npm run agents:build`. يعيد الأمر توليد `packages/mcp/catalog.json` ومراجع الـskill.
ينفذ `npm run docs:build` التحديث نفسه ويجهز ملفَي التنزيل. يختبر
`npm run test:agents` الاتصال والاكتشاف والبحث باللغتين والموارد والـprompt والمعاملات
غير الصحيحة والمكونات غير المعروفة.

يقرأ السيرفر الكتالوج المرفق فقط ويستخدم SDK TypeScript الرسمي مع stdio، ولا يوفّر
أدوات shell أو قراءة ملفات المشروع أو الشبكة. الكتالوج المثبت لقطة محددة؛ أعد توليده
أو تثبيته عند ترقية المكتبة. راجع [التحقق](./verification) للتغطية والحدود المتبقية.
