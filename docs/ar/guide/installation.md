# التثبيت

::: tip طبقة المزودات (غير منشورة)
يضيف الإصدار الرئيسي القادم مزودَي Vuetify وPrimeVue خلف واجهة واحدة، ويتطلب ملف plugin
وتكاملًا واحدًا مع Vite. راجع [المزودات والإعداد](./providers).
:::

ثبّت الحزمة العامة من npm داخل مشروع Vue 3.5 وVuetify 3.13.2+:

```sh
npm install wakeb-components@0.7.0
```

استورد CSS مرة واحدة في مدخل التطبيق، واحتفظ بإعداد Vuetify الحالي:

```ts
import 'vuetify/styles'
import 'wakeb-components/style.css'
```

في تطبيق جديد تحتاج أيضًا تسجيل Vuetify كـplugin:

```ts
import { createApp } from 'vue'
import { createVuetify } from 'vuetify'
import App from './App.vue'

createApp(App).use(createVuetify()).mount('#app')
```

```vue
<script setup lang="ts">
import { WTruncatedText, WSegmentedProgress, WSemiCircleGauge } from 'wakeb-components'
</script>
<template>
  <WTruncatedText label="أساس مشترك لكل فريق ومشروع" :length="20" />
  <WSegmentedProgress :value="65" label="65%" />
  <WSemiCircleGauge :value="75" label="75%" sub-label="الجودة" />
</template>
```

Vue وVuetify هما peers، وWakeb Utils 0.1.1 يُثبت من npm. الحزمة ESM لمشاريع
Vue التي تستخدم bundler. التطوير على Node22.14+. للعمل دون اتصال، احفظ
<a href="/downloads/wakeb-components-0.7.0.tgz" download>الأرشيف</a> داخل المشروع وثبّته محليًا.
احفظ package.json وملف القفل معًا.

## الإصدارات المدعومة

تنطبق هذه النطاقات على إصدار المزودات غير المنشور بعد (راجع [المزودات والإعداد](./providers)).
Vue وVite هما peers إلزاميان. أما Vuetify وPrimeVue و`@primeuix/themes` فهي peers اختيارية:
ثبّت peers المزود الذي تختاره فقط، ولن يعرض npm أي تحذير peer بخصوص المزود الآخر.

كل صف في الجدول التالي هو تثبيت مقفل لمشروع مستهلك داخل `tests/fixtures/peers`. صف «الحد الأدنى»
يثبّت أقل إصدار في كل نطاق معلن، وصف «الأحدث ضمن النطاق» يسجل أحدث الإصدارات التي حُلّ إليها النطاق
عند آخر تحديث لملف القفل. يثبّت `npm run check:peers` كل صف باستخدام `npm ci` والحزمة المعبأة، ثم
يتحقق من الأنواع بـ`tsc --strict`، ويبني المشروع للمتصفح (كل المكونات، ثم WButton وحده) ولـSSR،
ويتحقق من المخرجات المعروضة ومن أن الحزمة لا تضم إلا المزود المختار. يكتب السكربت هذا الجدول بنفسه،
ويفشل بناء التوثيق إذا اختلف الجدول أو ملفات التثبيت أو نطاقات `package.json`.

الإصدارات خارج هذه النطاقات غير مختبرة. PrimeVue 4.5.5 و`@primeuix/themes` 2.0.3 هما الحد الأدنى
والأحدث في نطاقيهما معًا، لذلك لا يختلف صفا PrimeVue إلا في Vue وVite. يلزم Node 22.14 أو أحدث.

أقل إصدار مدعوم من Vue هو 3.5.40، لأن تعريفات الأنواع في الحزمة تستخدم معامل نوع العنصر الذي أضافه
Vue 3.5.40 إلى `DefineComponent`. مع Vue من 3.5.0 إلى 3.5.39 تُبنى المكونات وتُعرض، لكن
`tsc --strict` يرفض التعريفات. وأصبح Vite peer إلزاميًا، لأن اختيار المزود يتم فقط عبر plugin
الخاص بـVite ‏`wakebComponents()`.
