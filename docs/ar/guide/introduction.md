# نظرة عامة

تضم Wakeb Components تسعة عشر مكونًا: النص المختصر، التقدم، المؤشر نصف الدائري، الصور المتداخلة، التحميل، Skeleton الصفحات، الخطوات الرأسية، الأزرار، الشارات، Accordion، مجموعات الشارات، شارة المستخدم، زر Tooltip، التبويبات، الشجرة، Dropdown، Carousel، قائمة التصدير وBaseSidebar.

Vue 3.5 وVuetify 3.13.2+ هما peers. استورد المكونات بالاسم من `wakeb-components` واستورد CSS مرة واحدة. لا تحتاج plugin تسجيل خاص أو router أو store أو نظام auto-import.

المكوّن العام يستقبل البيانات وخيارات العرض ويرسل الأحداث. الترجمة والصلاحيات وطلب البيانات وتوليد الملفات وschemas الفورم تظل في المشروع المستهلك. خصص المكونات عبر props وslots ومتغيرات CSS دون نسخ منطقها داخل كل مشروع.
