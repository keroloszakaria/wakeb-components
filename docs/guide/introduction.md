# Introduction

Wakeb Components provides twenty-one focused primitives: truncated text, segmented progress, a semicircle gauge, avatar stacks, a loading indicator, page skeletons, vertical steps, buttons, badges, accordion panels, badge stacks, user badges, tooltip buttons, tabs, trees, dropdown menus, carousels, export pickers sidebar shells, dialogs and drawers. Application colors, icons and translations stay in consumer adapters.

Vue 3.5 and Vuetify 3.13.2+ are peers. Import components by name from `wakeb-components`.
No registry plugin, route, store or auto-import convention is needed.

The package leaves forms, tables, domain-specific badges, permission
rules, data fetching and application layouts. They need their own contracts before
extraction. A reusable component receives data and presentation choices; the
application owns business behavior.

WModal and WDrawer add overlay shells, bringing the package to 21 components.
